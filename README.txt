わが家の作り置きキッチン（AIなし版）

内容
- 事前登録レシピ：肉・魚・豆腐/卵を中心に100品以上 + 定番料理20品
- 登録レシピから5日または7日分の夕食献立を自動作成（AI・APIキー不要）
- 献立の1日ごとの入れ替え、献立保存/呼び出し
- 食材名でレシピ検索、ユーザー独自レシピの追加/削除
- 献立に含まれるレシピの材料から買い物リスト作成、チェック、コピー
- 作り置き段取りチェック、メモ、JSONバックアップ/復元
- データは同じブラウザのlocalStorageに保存

iPhoneで使う
1. ZIPを展開します。
2. GitHubで既存のWebアプリのリポジトリを開きます。
3. 既存の index.html と同じ場所に、このフォルダ内の index.html、manifest.webmanifest、sw.js、icon-192.png、icon-512.png をアップロードして置き換えます。
4. 変更をCommitします。GitHub Pagesを使っている場合、反映まで少し待ってサイトを開き直します。
5. iPhoneのSafariでサイトを開き、共有ボタン →「ホーム画面に追加」。

注意
- 公開先URLやリポジトリ設定は含みません。
- 元のアプリと同じlocalStorageキーを使用していますが、元のチェック/メモ/献立データは可能な限り保持します。更新前に元アプリのバックアップを取ってください。
- 献立作成はルールベースのランダム選択です。AIによる栄養評価・在庫量計算ではありません。
- 材料の分量は家庭向けの目安です。アレルギー、年齢に応じた食べやすさ、食品の加熱・保存安全性を確認してください。
